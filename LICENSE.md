# Data licensing and source attribution

This repository contains two legally distinct kinds of material:

1. **DiagTrace-created benchmark material.** The project-created annotations, event organization, manifests, schemas, interaction records, audit files, and documentation are made available for research use as part of the DiagTrace benchmark release.
2. **Third-party source material.** Source-derived textual findings and excerpts originate from PubMed Central articles. Copyright and license terms for that content remain with the respective article copyright holders and publishers. Each case includes PMCID/PMC provenance so users can consult and comply with the article-specific license and attribution requirements.

No MIT license or other blanket software license is applied by this repository to third-party article content. Public redistribution approval for the benchmark does not replace the source articles' individual license terms.

Original PMC NXML/XML files, article PDFs, and figure images are not redistributed in this repository.

The software in the separate `Fanncg1229/DiagTrace-code` repository is licensed independently under the MIT License.
